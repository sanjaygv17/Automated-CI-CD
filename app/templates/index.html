Welcome to my Python Flask application. This project demonstrates an automated CI/CD pipeline using GitHub Actions, Docker, Docker Hub and Render. Every code update can trigger automated testing, container building and deployment.

Technology Stack

🐍 Python & Flask

Backend application developed using Python and Flask.

🧪 Pytest

Automated testing to verify application functionality.

🐳 Docker

Containerizes the application for consistent deployment.

⚙️ GitHub Actions

Automates testing, building and publishing the Docker image.

📦 Docker Hub

Stores and distributes the application Docker image.

🚀 Render

Hosts the containerized application online.

CI/CD Workflow

01. Code

Develop and push code to GitHub.

02. Test

GitHub Actions runs automated tests.

03. Build

Docker builds the application image.

04. Publish

Image is pushed to Docker Hub.

05. Deploy

Render hosts the application.
